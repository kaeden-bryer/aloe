# Aloe: Directing AI Use to Heal Society

Your unused AI, healing what matters. Aloe directs spare AI agent capacity toward
vetted open-source projects in climate, energy, farming and health. An AI steward
coordinates the work, verification is done by a different donor's agent, and only
the important decisions reach a human maintainer.

Hackathon proof of concept.

```bash
pnpm install
pnpm seed
pnpm dev        # http://localhost:5173
```
